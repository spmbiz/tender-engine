## Tier A — hunt now, with explicit prefilters

### A1 — France · Website maintenance / hosting / support — HUNT CORE
- Historical open cohort: **111 tenders / 103 buyers / 7 repeat buyers**.
- Median historical award: **EUR 260,000**.
- Historical winner concentration: top observed supplier **7.69%**.
- Historical DCE reality check: **3/3 sampled candidates gate-ready**.

## Execution doctrine

1. Historical market structure decides **what deserves DCE compute**, never whether SPM can bid.
2. First live kill-switches: reserved participation, entity/geography, hard certification/partner status, turnover minimum, mandatory references, named staffing/on-site, insurance/bond, and submission deadline.
3. Only after gates survive do we price/subcontract.
4. For physical broker lanes, obtain **2–5 normalized supplier quotes** against the exact DCE specification before estimating margin.
5. For AI-heavy language/creative lanes, AI is production leverage, not a substitute for any explicitly required qualified human, portfolio, reference or certification.
6. `UNKNOWN` stays UNKNOWN; it is never converted into a pass.
